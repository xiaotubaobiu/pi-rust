# LaTeX upstream oracle and generated tables

This directory is the portable evidence/generation entry for `src/tui/latex.rs`.
It runs the actual read-only upstream `packages/tui/src/latex.ts` and `utils.ts`
at pi HEAD `590144609`, not a second handwritten renderer and not Rust-generated
expected values. `source-manifest.json` records the complete source hashes.
The derived code/tables retain upstream attribution in `PI-LICENSE.txt`.

## Reproduce offline

From the pi-rust root, using Node v25.8.2 and the installed Rust formatter:

```powershell
& C:/Users/13063/anaconda3/node.exe docs/migration/reference/latex/run.mjs
```

The three optional positional arguments are the pi checkout, dependency-cache
root, and scratch directory. Defaults are sibling `pi`, sibling
`.migration-handoff/reference-deps`, and `pi-rust/target/latex-oracle`.
Only scratch files are written. Never point scratch inside pi. The bootstrap
rejects an upstream revision different from the audited reference and rejects
scratch paths whose resolved existing ancestor is inside pi. No npm/network or
paid-provider call is needed. The dependency cache needs the extracted
`get-east-asian-width-1.6.0` package (either directly or in its `package/` folder).
No marked/chalk dependency is needed for this independent LaTeX oracle.

Outputs:
- `tables.rs`: 15 source-derived mapping/set tables, formatted by rustfmt.
- `fixtures.json`: 2,763 direct upstream input/output cases, including all 149
  assertions from all 111 upstream test blocks, plus table coverage, inline and
  display layout, matrices/cases, malformed/streamed input, whitespace and
  well-formed Unicode boundaries. Upstream original literal assertions execute
  before fixture output is accepted.
- `utf16-domain.json`: 22 historical regression cases, preserving their original

- `utf16-fixtures.json`: 3,278 raw UTF-16 rendering and 12,415 raw width cases.
  Lone units, valid pairs, script/argument splitting, joining, ANSI, marks,
  malformed TeX, layout markers, all surrogate values and seeded compositions.
- `source-manifest.json`: source revision/hashes, table cardinalities, runtime
  versions and all output hashes/counts.

Checked-in copies: `src/tui/latex/tables.rs`, `src/tui/latex/fixtures.json`,
`src/tui/latex/utf16-fixtures.json`, and this directory's manifest/domain ledger.
Regenerate and compare all five artifacts byte-for-byte before replacing them.
Rust independently checks hashes/counts against the manifest. Expected fixtures
come only from upstream, never from Rust. The corpora overlap; do not add their
row counts as unique inputs or confuse them with Rust test-function counts.

## Current implementation and UTF-16 APIs

The previous all-None placeholder is replaced by command/argument parsing,
symbols/scripts, fractions/roots, named/limit operators, accents/wrappers,
environments, matrices and baseline-aware multiline layout. Unsupported syntax
returns None where upstream returns undefined. All seven formerly deferred
Markdown cases execute; no pending whitelist remains.

Internally, text retains actual Vec<u16> units, including lone surrogates. JS
code-unit indexing/unbraced arguments and Unicode code-point property operations
remain distinct. This is not an encoding through colliding private-use sentinels;
upstream's existing private-use layout protocol is unchanged.

- `render_latex_utf16(&[u16], RenderLatexOptions) -> Option<Vec<u16>>` preserves raw
  units through parsing, formatting, widths, layout and concatenation.
- `render_latex(&str, RenderLatexOptions) -> Option<String>` shares that engine and
  calls String::from_utf16_lossy only at its public UTF-8 return boundary.
- Raw visible width keeps lone surrogate nonprinting behavior distinct from real
  U+FFFD. An ephemeral segmentation view maps each point back to original units;
  it is not rendered content. Tests check the relevant grapheme, Indic-conjunct
  and ExtendedPictographic properties as well as observed upstream widths.

For display `\frac1😀`, upstream raw output is
`[49, 10, 9472, 32, 56832, 10, 55357]` and encoded output is `1\n─ �\n�`.
The old scalar implementation instead kept the emoji paired; the red regression
is retained, and both corrected paths now match. All 22 historical domain cases
retain their expectations and are checked via both APIs.
