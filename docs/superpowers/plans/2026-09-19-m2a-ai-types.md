# M2a AI 类型系统完整移植 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port upstream `packages/ai` types.ts + utils/transcript.ts to Rust with byte-compatible JSON, building the full type layer M2b-c API ports compile against.

**Architecture:** New modules under `src/ai/types/` and `src/ai/transcript.rs` are built alongside the existing M1 mini-types; Task 10 swaps M1 code (agent/cli/providers) onto the full types and removes the old ones. Serde wire format must match upstream JSON exactly (see spec §2).

**Tech Stack:** Existing crate deps (serde, serde_json, schemars, tokio). No new deps.

**Spec:** `docs/superpowers/specs/2026-09-19-m2-pi-ai-full-port.md`

**Port style (differs from M1):** This is a port of existing upstream source. Tasks name upstream files — implementers MUST read them at `C:/Users/13063/Desktop/code/pi/packages/ai/src/` (snapshot commit `5901446`) and port behavior faithfully. The Rust signatures and test lists below are the binding contract; the upstream source is the reference for every field, default, and edge case. Where upstream has behavior M1 didn't model (e.g. `deferred` stop reason, sections replay), the port must include it.

## Global Constraints

- Rust edition 2021, no `unsafe`, single crate, layering `cli → agent → ai` unchanged.
- Serde wire format byte-compatible with upstream JSON (spec §2): role/type tag values and camelCase field names exactly as upstream (`toolCallId`, `stopReason`, `cacheRead`, `toolUse`, ...). Every type gets a round-trip test against a pinned JSON fixture.
- Enum variant sets exactly match upstream: StopReason 7 values; KnownApi 10; KnownProvider 38.
- New code lives in `src/ai/types/` (module tree) + `src/ai/transcript.rs`; do not modify existing M1 files until Task 10.
- `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt` must be clean at every commit.
- Commit messages: `{feat,fix,docs,chore}: <message>`.
